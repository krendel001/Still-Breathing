# Changelog

All notable changes to **Still-Breathing** are documented here.

Format based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.4.7] - 2026-06-20

### Added
- Knockout state: lethal damage downed players instead of killing them instantly
- Bleed-out timer with on-screen countdown
- Self-revive by holding Sneak (risky — failure means death)
- Passive self-recovery rolls over time
- Ally revive via Shift + Right-click
- Finish-off mechanic for downed players (melee hits)
- Inventory looting while a player is knocked out
- Give Up option to accept death
- Post-recovery grace period and exhaustion stacks
- GeckoLib lying-down animation
- HUD overlays with revive and self-revive progress
- Admin test dummy commands (`/knockout dummy ...`)
- Optional Epic Fight compatibility
- English and Russian localization
- Fully server-side configurable settings
